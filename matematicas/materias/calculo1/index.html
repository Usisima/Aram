Propiedades básicas de los números

P1 · Asociatividad

a+(b+c)=(a+b)+ca + (b + c) = (a + b) + ca+(b+c)=(a+b)+c

P2 · Existencia de una identidad para la suma

a+0=0+a=aa + 0 = 0 + a = aa+0=0+a=a

P3 · Existencia de inversos para la suma

a+(−a)=(−a)+a=0a + (-a) = (-a) + a = 0a+(−a)=(−a)+a=0

P4 · Ley conmutativa para la suma

a+b=b+aa + b = b + aa+b=b+a

P5 · Ley asociativa para la multiplicación

a⋅(b⋅c)=(a⋅b)⋅ca \cdot (b \cdot c) = (a \cdot b) \cdot ca⋅(b⋅c)=(a⋅b)⋅c

P6 · Existencia de una identidad para la multiplicación

a⋅1=1⋅a=a,1≠0a \cdot 1 = 1 \cdot a = a, \quad 1 \neq 0a⋅1=1⋅a=a,1=0

P7 · Existencia de inversos para la multiplicación

a⋅a−1=a−1⋅a=1,a≠0a \cdot a^{-1} = a^{-1} \cdot a = 1, \quad a \neq 0a⋅a−1=a−1⋅a=1,a=0

P8 · Ley conmutativa para la multiplicación

a⋅b=b⋅aa \cdot b = b \cdot aa⋅b=b⋅a

P9 · Ley distributiva

a⋅(b+c)=a⋅b+a⋅ca \cdot (b + c) = a \cdot b + a \cdot ca⋅(b+c)=a⋅b+a⋅c
